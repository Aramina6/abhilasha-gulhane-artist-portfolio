# Overleaf artist CV

One-page CV for galleries. Source: `main.tex`.

## Open in Overleaf

1. Go to [overleaf.com](https://www.overleaf.com) and sign in.
2. New Project → Upload Project.
3. Upload `main.tex` (or zip this `overleaf` folder).
4. Set compiler to **pdfLaTeX** (Menu → Compiler).
5. Recompile. Download PDF.

A matching PDF is also generated locally as `../Abhilasha_Gulhane_Artist_CV.pdf` if you cannot use Overleaf immediately.
